# Notes

Notes are the heart of your patina. Each one captures something you've done — a project, a skill you've built, a decision you made, a win — in your own words. They're the evidence everything else is built from: your skill inventory, and any drafts a module generates for you.

## How to add a note

Run `/add <description>` and Claude will ask a few short questions and write the note for you. You don't need to create files in here by hand.

## File naming

Notes use a plain slug based on the subject — for example `react-native.md` or `client-onboarding.md`. No date prefix; the `date:` field inside the note records when it was written.

## What makes a good note

- One specific example beats three vague ones.
- Real outcomes — what shipped, what changed, what it led to.
- Your own voice, not buzzwords.

## What not to put here

- Claims you can't back up with a specific example.
- Generic descriptions of job duties.
