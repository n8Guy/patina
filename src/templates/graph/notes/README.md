# Notes

Supplemental notes that don't come from the automated ingestion pipeline. Use these to document:

- Personal projects and side work
- Prior-role experience worth preserving
- External contributions (open source, writing, talks)
- Certifications and courses
- Anything not visible in your work system data

Notes here are **first-class evidence** — weighted the same as weekly summaries and monthly profiles when generating skills and profile proposals.

## How to add a note

Run `/add <description>` and Claude will ask clarifying questions and write the note for you.

## File naming

- Evergreen content (a skill, a project): `slug.md` (e.g. `react-native.md`)
- Time-bound content: `YYYY-MM-DD-slug.md` (e.g. `2026-05-01-conference-talk.md`)

## What not to put here

- Claims you can't back up with specifics
- Things already captured in your weekly summaries
- Generic descriptions of job duties
